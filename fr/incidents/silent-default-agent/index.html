L'agent par défaut, en silence

Ce qui a cassé

Devant un chemin de profil inexistant, le harnais est sorti en 0 avec une erreur standard vide et a lancé l'agent par défaut — octet pour octet le prompt système du témoin. Et la forme courte du drapeau chargeait le profil en mode sans interface et ne chargeait rien dans le terminal interactif, sans une ligne d'échec, pas même dans le journal de débogage de la CLI.

La règle qu'il a payée

Le lanceur résout le profil lui-même, depuis le commit de gouvernance, avant que quoi que ce soit démarre ; le régime fait partie de l'affirmation, et chaque refus le nomme.
