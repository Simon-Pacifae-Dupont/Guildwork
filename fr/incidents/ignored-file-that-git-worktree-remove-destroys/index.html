Le fichier ignoré que git worktree remove détruit

Ce qui a cassé

Un fichier ignoré par git, ou tout fichier non suivi sous une configuration courante, est détruit par un git worktree remove qui sort en 0 sans --force — reproduit sur deux versions de Git. Une révision antérieure de la documentation de l'outil affirmait qu'un garde-fou existait, et c'est cette affirmation qui a rendu le trou invisible à la revue de l'outil lui-même.

La règle qu'il a payée

La condition 2 demande explicitement le non suivi et l'ignoré ; la seule exception est un manifeste commité qu'une personne a écrit.
