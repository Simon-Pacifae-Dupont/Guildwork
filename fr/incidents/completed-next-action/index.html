L'action suivante déjà accomplie

Ce qui a cassé

Une session s'est ouverte sur une branche sans entrée de journal ; l'entrée est donc retombée sur une entrée plus ancienne dont l'action suivante disait « autoriser la phase 3 » — alors que HEAD était le commit de fusion qui avait livré la phase 3. L'entrée n'avait pas été remplacée ; elle avait été accomplie, par une session dont la propre entrée dormait encore dans une pull request ouverte.

La règle qu'il a payée

La précédence classe des sources, pas des affirmations. Une action suivante que Git dément déjà n'est plus d'actualité, quel que soit son rang, et l'entrée qui l'emporte le dit.

Incident précédentUn vrai test de la passationIncident suivantLa limite de 400 caractères

Les quarante-sept incidents et la règle que chacun a payée sont publics dans le kit Guildwork, sous licence MIT. Chaque exemple est réécrit sur un projet fictif nommé Lantern : les mécaniques sont réelles, le produit ne l'est pas.
