Le commit qui vivait dans un atelier

Ce qui a cassé

Un clone de session qui pouvait cloner mais pas pousser a porté un commit toute une soirée. Les fichiers qu’il contenait ont été livrés par une autre route et publiés sous un commit que le clone n’a jamais vu. La session suivante a trouvé le commit du clone, l’a pris pour la vérité versionnée, et s’apprêtait à reconstruire le travail publié sur une base qui n’existait plus nulle part ailleurs.

La règle qu'il a payée

Durable veut dire atteignable depuis une référence poussée, y compris pour l’atelier d’un siège. Un clone qui ne peut pas pousser ne garde ni commit ni fichier modifié entre deux tours : il transforme, livre, et se remet sur la tête publiée. Ce qui a été préparé vit dans les fichiers livrés et dans le script rejouable, jamais dans le clone.
